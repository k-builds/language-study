# Infinite Match

A Gurmukhi alphabet flashcard matching game built with React and Vite.

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:5173 to view it in the browser.

## Build

```bash
npm run build
```

The static site is generated to `dist/` and can be served with any static host or GitHub Pages.

## Deploy to GitHub Pages

Push your changes to `main`. The GitHub Actions workflow will automatically:

1. Build the static site (`npm run build`)
2. Deploy it to `https://k-builds.github.io/language-study/`

Enable GitHub Pages in your repo settings (Source: "GitHub Actions").
